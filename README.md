# 🚀 Relay Раздача — Распределение ETH через Relay

Софт для автоматической раздачи ETH с основного кошелька на множество адресов через [Relay](https://relay.link) — кроссчейн мост, поддерживающий 85+ сетей.

> 📢 **Telegram канал:** https://t.me/goathamdao

---

## 📋 Возможности

- ✅ Отправка ETH на множество адресов одной командой
- ✅ Выбор исходной и целевой сети (кроссчейн)
- ✅ Указание суммы в ETH или в % от баланса
- ✅ Рандомизация суммы в заданном диапазоне
- ✅ Задержки между транзакциями для безопасности
- ✅ Поддержка 13+ сетей (Ethereum, Arbitrum, Base, Optimism и др.)

## 📦 Установка

### 1. Клонирование репозитория

```bash
git clone https://github.com/GOATHAMDAO/relay-razdacha.git
cd relay-razdacha
```

### 2. Создание виртуального окружения

```bash
python -m venv venv
```

### 3. Активация виртуального окружения

**Windows (PowerShell):**
```powershell
.\venv\Scripts\Activate.ps1
```

**Windows (CMD):**
```cmd
.\venv\Scripts\activate.bat
```

**Linux / macOS:**
```bash
source venv/bin/activate
```

> ⚠️ После активации вы увидите `(venv)` в начале строки терминала.

### 4. Установка зависимостей

```bash
pip install -r requirements.txt
```

## ⚙️ Настройка

### 1. Приватный ключ

Создайте файл `user_data/private_key.txt` и вставьте приватный ключ вашего **основного кошелька**:

```
0xВАШ_ПРИВАТНЫЙ_КЛЮЧ_БЕЗ_ПРОБЕЛОВ
```

> ⚠️ **ВАЖНО:** Никогда не делитесь приватным ключом! Храните его в безопасности.

### 2. Адреса получателей

Создайте файл `user_data/recipients.txt` и добавьте адреса получателей (каждый адрес с новой строки):

```
0x1234567890123456789012345678901234567890
0xabcdefabcdefabcdefabcdefabcdefabcdefabcd
0x9876543210987654321098765432109876543210
```

### 3. Конфигурация (config.py)

Откройте файл `config.py` и настройте параметры:

```python
# Сеть ИЗ которой отправлять
CHAIN_FROM = 'ARBITRUM'

# Сеть В которую отправлять
CHAIN_TO = 'BASE'

# Тип суммы: 'Absolute' (в ETH) или 'Percent' (% от баланса)
AMOUNT_TYPE = 'Absolute'

# Диапазон сумм [минимум, максимум]
AMOUNT_RANGE = [0.001, 0.002]

# Задержка между транзакциями (секунды)
TRANSACTIONS_DELAY = [30, 60]
```

Настройки выполнения Relay:

```python
# Необязательный ручной слипаж для котировки Relay в базисных пунктах.
# Оставьте параметр закомментированным для автоматического слипажа.
# SLIPPAGE_TOLERANCE_BPS = 600

# Максимальное время ожидания выполнения перевода Relay в целевой сети.
RELAY_STATUS_TIMEOUT = 300
RELAY_STATUS_POLL_INTERVAL = 2
```

Программа считает раздачу успешной только после подтверждения перевода Relay
в целевой сети. Если цена изменится сильнее заданного слипажа, Relay может
вернуть исходный депозит на кошелёк отправителя.

Адреса, для которых произошла ошибка, записываются в `user_data/failed.txt` —
по одному адресу кошелька в каждой строке. Файл очищается в начале каждой
подтверждённой раздачи, поэтому содержит только ошибки последнего запуска.

### 4. Прокси (опционально)

Если нужно использовать прокси, создайте файл `user_data/proxies.txt`:

```
login:password@ip:port
```

И включите в `config.py`:
```python
USE_PROXIES_IN_WEB3 = True
```

## ❓ FAQ

### Ошибка "Приватный ключ не найден"
Создайте файл `user_data/private_key.txt` и вставьте приватный ключ.

### Ошибка "Баланс аккаунта равен 0"
Пополните баланс кошелька в сети, из которой отправляете (CHAIN_FROM).

### Ошибка "Указанная сумма превышает баланс"
Уменьшите значения в AMOUNT_RANGE или используйте режим Percent.

### Ошибка при установке зависимостей
Убедитесь, что используете Python 3.10+ и активировали venv.
